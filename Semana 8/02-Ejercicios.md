## 1) Simplifique las siguientes expresiones racionales

### a)

3 / (2x + 4) - 2x / (x^2 - 4)

Factorizamos denominadores:

2x + 4 = 2(x + 2)  
x^2 - 4 = (x - 2)(x + 2)

Entonces:

3 / 2(x + 2) - 2x / (x - 2)(x + 2)

El mínimo común denominador es:

2(x - 2)(x + 2)

Reescribiendo:

= 3(x - 2) / 2(x - 2)(x + 2) - 4x / 2(x - 2)(x + 2)

Operando numeradores:

= [3(x - 2) - 4x] / 2(x - 2)(x + 2)  
= (3x - 6 - 4x) / 2(x - 2)(x + 2)  
= (-x - 6) / 2(x - 2)(x + 2)

**Resultado:** (-x - 6) / 2(x - 2)(x + 2)  
**Restricciones:** x ≠ -2, x ≠ 2

---

### b)

(x^2 - 1) / x^3 - 2x / (x^2 + 7)

El mínimo común denominador es:

x^3(x^2 + 7)

Reescribiendo:

= (x^2 - 1)(x^2 + 7) / x^3(x^2 + 7) - 2x(x^3) / x^3(x^2 + 7)

Operando:

= [(x^2 - 1)(x^2 + 7) - 2x^4] / x^3(x^2 + 7)

Desarrollando:

(x^2 - 1)(x^2 + 7) = x^4 + 7x^2 - x^2 - 7 = x^4 + 6x^2 - 7

Entonces:

= (x^4 + 6x^2 - 7 - 2x^4) / x^3(x^2 + 7)  
= (-x^4 + 6x^2 - 7) / x^3(x^2 + 7)

**Resultado:** (-x^4 + 6x^2 - 7) / x^3(x^2 + 7)  
**Restricción:** x ≠ 0

---

### c)

(3x - 1) / (x^2 - 9) · (x + 3) / 2x

Factorizamos:

x^2 - 9 = (x - 3)(x + 3)

Entonces:

= (3x - 1) / (x - 3)(x + 3) · (x + 3) / 2x

Simplificando el factor común (x + 3):

= (3x - 1) / 2x(x - 3)

**Resultado:** (3x - 1) / 2x(x - 3)  
**Restricciones:** x ≠ -3, x ≠ 0, x ≠ 3

---

### d)

(x - 4) / (x^2 - 4) + (x^2 - 3x - 4) / (x^2 + 5x + 6)

Factorizamos:

x^2 - 4 = (x - 2)(x + 2)  
x^2 - 3x - 4 = (x - 4)(x + 1)  
x^2 + 5x + 6 = (x + 2)(x + 3)

Entonces:

= (x - 4) / (x - 2)(x + 2) + (x - 4)(x + 1) / (x + 2)(x + 3)

El mínimo común denominador es:

(x - 2)(x + 2)(x + 3)

Reescribiendo:

= (x - 4)(x + 3) / (x - 2)(x + 2)(x + 3) + (x - 4)(x + 1)(x - 2) / (x - 2)(x + 2)(x + 3)

Sacando factor común en el numerador:

= (x - 4)[(x + 3) + (x + 1)(x - 2)] / (x - 2)(x + 2)(x + 3)

Desarrollando:

(x + 1)(x - 2) = x^2 - x - 2

Entonces:

= (x - 4)[(x + 3) + (x^2 - x - 2)] / (x - 2)(x + 2)(x + 3)  
= (x - 4)(x^2 + 1) / (x - 2)(x + 2)(x + 3)

**Resultado:** (x - 4)(x^2 + 1) / (x - 2)(x + 2)(x + 3)  
**Restricciones:** x ≠ 2, x ≠ -2, x ≠ -3
