## 2) Factorización completa usando la fórmula general

### a) 8a^2 - 12a + 4

8a^2 - 12a + 4 = 0

a = 8  
b = -12  
c = 4

Δ = (-12)^2 - 4(8)(4)  
Δ = 144 - 128  
Δ = 16

a = (-b ± √Δ) / 2a  
a = (12 ± 4) / 16

a1 = (12 + 4) / 16 = 16/16 = 1  
a2 = (12 - 4) / 16 = 8/16 = 1/2

Entonces:

8a^2 - 12a + 4 = 8(a - 1)(a - 1/2)

Sacando la fracción del factor:

= 4(a - 1)(2a - 1)

**Resultado:** 4(a - 1)(2a - 1)

---

### b) 5m^2 - 3m

Sacando factor común:

= m(5m - 3)

**Resultado:** m(5m - 3)

---

### c) 6r^2 - r

Sacando factor común:

= r(6r - 1)

**Resultado:** r(6r - 1)

## 3) Realice los siguientes ejercicios

### a) -8x^3 + 4x^2 - 16x

Sacando factor común:

= -4x(2x^2 - x + 4)

**Resultado:** -4x(2x^2 - x + 4)

---

### b) x^3 + 2x^2 + 3x + 6

Agrupando:

= (x^3 + 2x^2) + (3x + 6)  
= x^2(x + 2) + 3(x + 2)  
= (x + 2)(x^2 + 3)

**Resultado:** (x + 2)(x^2 + 3)

---

### c) 4x^2 - 12x + 9

Reconociendo trinomio cuadrado perfecto:

= (2x)^2 - 2(2x)(3) + 3^2  
= (2x - 3)^2

**Resultado:** (2x - 3)^2

---

### d) 9a^2 - 25b^2

Reconociendo diferencia de cuadrados:

= (3a)^2 - (5b)^2  
= (3a - 5b)(3a + 5b)

**Resultado:** (3a - 5b)(3a + 5b)
