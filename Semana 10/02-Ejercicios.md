## Ecuaciones lineales

### Ejercicio 1

3x − 7 = 2x + 5

Pasamos el término con x al lado izquierdo y los números al lado derecho:

3x − 2x = 5 + 7

x = 12

**Resultado:** x = 12

**Comprobación:** 3(12) − 7 = 36 − 7 = 29 | 2(12) + 5 = 24 + 5 = 29 ✓

---

### Ejercicio 2

5(x + 2) − 3 = 4(x − 1) + 6

Aplicamos la propiedad distributiva:

5x + 10 − 3 = 4x − 4 + 6

Simplificamos cada lado:

5x + 7 = 4x + 2

Pasamos términos semejantes:

5x − 4x = 2 − 7

x = −5

**Resultado:** x = −5

**Comprobación:** 5(−5 + 2) − 3 = 5(−3) − 3 = −15 − 3 = −18 | 4(−5 − 1) + 6 = 4(−6) + 6 = −24 + 6 = −18 ✓

---

### Ejercicio 3

2x / (x − 3) = 4

Multiplicamos ambos lados por (x − 3):

2x = 4(x − 3)

2x = 4x − 12

2x − 4x = −12

−2x = −12

x = 6

**Verificación de restricción:** x ≠ 3, y como x = 6 ≠ 3, el valor es válido.

**Resultado:** x = 6

**Comprobación:** 2(6) / (6 − 3) = 12 / 3 = 4 ✓

## Ecuaciones cuadráticas

### Ejercicio 4

x² − 5x + 6 = 0

Identificamos los coeficientes: a = 1, b = −5, c = 6

Factorizamos buscando dos números que multiplicados den 6 y sumados den −5:

(−2)(−3) = 6 y (−2) + (−3) = −5

Entonces:

(x − 2)(x − 3) = 0

x − 2 = 0 → x = 2
x − 3 = 0 → x = 3

**Resultado:** S = {2, 3}

**Comprobación:**
x = 2: (2)² − 5(2) + 6 = 4 − 10 + 6 = 0 ✓
x = 3: (3)² − 5(3) + 6 = 9 − 15 + 6 = 0 ✓

---

### Ejercicio 5

2x² + 3x − 2 = 0

Identificamos los coeficientes: a = 2, b = 3, c = −2

Aplicamos la fórmula cuadrática:

x = (−b ± √(b² − 4ac)) / 2a

Calculamos el discriminante:

Δ = b² − 4ac = (3)² − 4(2)(−2) = 9 + 16 = 25

x = (−3 ± √25) / 2(2) = (−3 ± 5) / 4

x₁ = (−3 + 5) / 4 = 2 / 4 = 1/2
x₂ = (−3 − 5) / 4 = −8 / 4 = −2

**Resultado:** S = {−2, 1/2}

**Comprobación:**
x = 1/2: 2(1/4) + 3(1/2) − 2 = 1/2 + 3/2 − 2 = 4/2 − 2 = 0 ✓
x = −2: 2(4) + 3(−2) − 2 = 8 − 6 − 2 = 0 ✓

---

### Ejercicio 6

x² − 6x + 9 = 0

Identificamos los coeficientes: a = 1, b = −6, c = 9

Reconocemos el trinomio cuadrado perfecto:

(x − 3)² = 0

x − 3 = 0 → x = 3

Es una raíz doble (o repetida).

**Resultado:** S = {3}

**Comprobación:** (3)² − 6(3) + 9 = 9 − 18 + 9 = 0 ✓

## Ecuaciones con valor absoluto

### Ejercicio 7

|x − 5| = 8

Por definición de valor absoluto, se generan dos casos:

**Caso 1:** x − 5 = 8
x = 8 + 5
x = 13

**Caso 2:** x − 5 = −8
x = −8 + 5
x = −3

**Resultado:** S = {−3, 13}

**Comprobación:**
x = 13: |13 − 5| = |8| = 8 ✓
x = −3: |−3 − 5| = |−8| = 8 ✓

---

### Ejercicio 8

|2x + 3| = 11

**Caso 1:** 2x + 3 = 11
2x = 11 − 3
2x = 8
x = 4

**Caso 2:** 2x + 3 = −11
2x = −11 − 3
2x = −14
x = −7

**Resultado:** S = {−7, 4}

**Comprobación:**
x = 4: |2(4) + 3| = |8 + 3| = |11| = 11 ✓
x = −7: |2(−7) + 3| = |−14 + 3| = |−11| = 11 ✓

## Ecuaciones con radicales

### Ejercicio 9

√(2x + 3) = 5

Elevamos ambos miembros al cuadrado:

(√(2x + 3))² = 5²

2x + 3 = 25

2x = 25 − 3

2x = 22

x = 11

**Verificación de dominio:** 2(11) + 3 = 25 ≥ 0 ✓

**Resultado:** x = 11

**Comprobación:** √(2(11) + 3) = √(22 + 3) = √25 = 5 ✓

---

### Ejercicio 10

√(x + 1) = x − 1

**Condición de dominio:** x + 1 ≥ 0 → x ≥ −1, y además x − 1 ≥ 0 → x ≥ 1

Elevamos ambos miembros al cuadrado:

x + 1 = (x − 1)²

x + 1 = x² − 2x + 1

Reorganizamos:

0 = x² − 2x + 1 − x − 1

0 = x² − 3x

0 = x(x − 3)

x = 0 o x = 3

**Verificación:**
x = 0: √(0 + 1) = √1 = 1, pero x − 1 = 0 − 1 = −1. Como 1 ≠ −1, se descarta (solución extraña).
x = 3: √(3 + 1) = √4 = 2, y x − 1 = 3 − 1 = 2. Como 2 = 2 ✓

**Resultado:** x = 3

## Inecuaciones cuadráticas

### Ejercicio 12

x² − 5x + 6 > 0

Factorizamos:

(x − 2)(x − 3) > 0

Los puntos críticos son x = 2 y x = 3.

Analizamos los signos en cada intervalo:

| Intervalo | (x − 2) | (x − 3) | Producto |
|-----------|---------|---------|----------|
| x < 2     | −       | −       | +        |
| 2 < x < 3 | +       | −       | −        |
| x > 3     | +       | +       | +        |

El producto es positivo cuando x < 2 o x > 3.

**Resultado en notación de intervalo:** ]−∞, 2[ ∪ ]3, +∞[

**Verificación:**
x = 0: (0)² − 5(0) + 6 = 6 > 0 ✓
x = 2.5: (2.5)² − 5(2.5) + 6 = 6.25 − 12.5 + 6 = −0.25 < 0 (fuera del conjunto solución) ✓
x = 4: (4)² − 5(4) + 6 = 16 − 20 + 6 = 2 > 0 ✓

---

### Ejercicio 13

x² − 4 ≤ 0

Factorizamos como diferencia de cuadrados:

(x − 2)(x + 2) ≤ 0

Los puntos críticos son x = −2 y x = 2.

Analizamos los signos en cada intervalo:

| Intervalo | (x − 2) | (x + 2) | Producto |
|-----------|---------|---------|----------|
| x < −2    | −       | −       | +        |
| −2 < x < 2| −       | +       | −        |
| x > 2     | +       | +       | +        |

El producto es negativo o cero cuando −2 ≤ x ≤ 2.

**Resultado en notación de intervalo:** [−2, 2]

**Verificación:**
x = 0: (0)² − 4 = −4 ≤ 0 ✓
x = −3: (−3)² − 4 = 9 − 4 = 5 > 0 (fuera del conjunto solución) ✓

## Inecuaciones con valor absoluto

### Ejercicio 14

|x − 3| < 5

Por definición, esto equivale a:

−5 < x − 3 < 5

Sumamos 3 a todos los miembros:

−5 + 3 < x < 5 + 3

−2 < x < 8

**Resultado en notación de intervalo:** ]−2, 8[

**Verificación:**
x = 0: |0 − 3| = 3 < 5 ✓
x = −3: |−3 − 3| = 6 < 5 es falso (fuera del conjunto solución) ✓

### Ejercicio 15

|2x + 1| ≥ 7

Por definición, esto equivale a dos casos:

**Caso 1:** 2x + 1 ≥ 7
2x ≥ 6
x ≥ 3

**Caso 2:** 2x + 1 ≤ −7
2x ≤ −8
x ≤ −4

**Resultado en notación de intervalo:** ]−∞, −4] ∪ [3, +∞[

**Verificación:**
x = 5: |2(5) + 1| = |11| = 11 ≥ 7 ✓
x = −5: |2(−5) + 1| = |−9| = 9 ≥ 7 ✓
x = 0: |2(0) + 1| = |1| = 1 ≥ 7 es falso (fuera del conjunto solución) ✓
