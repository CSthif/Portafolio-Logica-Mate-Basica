## 1) Determine el valor numérico de la siguiente expresión

### a)

8mp^4 - p, si m = 3, p = -2

Sustituyendo:

= 8(3)(-2)^4 - (-2)  
= 8(3)(16) + 2  
= 384 + 2  
= 386

**Resultado:** 386

---

### b)

3a^2 - 2b + c, si a = 2, b = 5, c = 4

Sustituyendo:

= 3(2)^2 - 2(5) + 4  
= 3(4) - 10 + 4  
= 12 - 10 + 4  
= 6

**Resultado:** 6

---

### c)

4x - 2y^2 + z, si x = -3, y = -2, z = 5

Sustituyendo:

= 4(-3) - 2(-2)^2 + 5  
= -12 - 2(4) + 5  
= -12 - 8 + 5  
= -15

**Resultado:** -15

---

### d)

a^2 - 2b(c - d), si a = -3, b = 2, c = 1, d = -1

Sustituyendo:

= (-3)^2 - 2(2)(1 - (-1))  
= 9 - 4(2)  
= 9 - 8  
= 1

**Resultado:** 1

## 2) Resuelva las siguientes operaciones

### a)

(x^4 - 2x^3 + 5x + 8) + (6x^4 - 9x^3 - 7x^2 + 1)

Agrupando términos semejantes:

= x^4 - 2x^3 + 5x + 8 + 6x^4 - 9x^3 - 7x^2 + 1  
= (x^4 + 6x^4) + (-2x^3 - 9x^3) - 7x^2 + 5x + (8 + 1)  
= 7x^4 - 11x^3 - 7x^2 + 5x + 9

**Resultado:** 7x^4 - 11x^3 - 7x^2 + 5x + 9

---

### b)

(9x^4 - 2x^3 + 5x + 12) - (6x^4 + 9x^3 - 2x^2 + 1)

Primero se cambia el signo al segundo paréntesis:

= 9x^4 - 2x^3 + 5x + 12 - 6x^4 - 9x^3 + 2x^2 - 1

Agrupando términos semejantes:

= (9x^4 - 6x^4) + (-2x^3 - 9x^3) + 2x^2 + 5x + (12 - 1)  
= 3x^4 - 11x^3 + 2x^2 + 5x + 11

**Resultado:** 3x^4 - 11x^3 + 2x^2 + 5x + 11

---

### c)

(3x + y)(2x - 5y)

Aplicando la propiedad distributiva:

= (3x)(2x) + (3x)(-5y) + (y)(2x) + (y)(-5y)  
= 6x^2 - 15xy + 2xy - 5y^2  
= 6x^2 - 13xy - 5y^2

**Resultado:** 6x^2 - 13xy - 5y^2

---

### d)

(2x - 5y)^2

Usando la fórmula notable:

(a - b)^2 = a^2 - 2ab + b^2

Entonces:

= (2x)^2 - 2(2x)(5y) + (5y)^2  
= 4x^2 - 20xy + 25y^2

**Resultado:** 4x^2 - 20xy + 25y^2
