## 1) Práctica de valor numérico (pág. 4)

### 1.

Calcule el valor numérico de:

4a^2b - 2b^3, cuando a = -1 y b = 2

Sustituyendo:

= 4(-1)^2(2) - 2(2)^3  
= 4(1)(2) - 2(8)  
= 8 - 16  
= -8

**Resultado:** -8

---

### 2.

Calcule el valor numérico de:

R(x) = (x^3 + 5) / (x - 2), para x = 4

Sustituyendo:

R(4) = (4^3 + 5) / (4 - 2)  
= (64 + 5) / 2  
= 69 / 2

**Resultado:** 69/2
